## 拷入

将本包内 `server/` 目录按相同路径复制进项目（本暂存目录届时已位于项目根）。只复制后端实现与随行测试，不包含前端文件。

- 群聊现有逻辑的协议标记与资料同步挂钩不在模块包内改文件，已单独暂存为 `patches/d5bbaa3_craft-group-hooks.diff`；启用群聊联动时按该补丁说明另行套用。

## 缝合（共 2 处，全部单行插入）

1. `server/src/index.ts` 的路由 import 区，新增一行：

   ```ts
   import craftProfitRouter from './routes/dashboard/craft-profit';
   ```

2. `server/src/index.ts` 的 `proxyFallback` 之前，新增一行：

   ```ts
   app.use('/api/craft-profit', craftProfitRouter);
   ```

无新增 npm / Python 依赖，无需修改 `package.json` 或 `pyproject.toml`。
