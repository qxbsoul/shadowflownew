来源：上游 176f101734ff9aa73f76920246a8a1439bf2a554（PR #45）、6479765d38a3ba7856d77d8c0546a7befb536ac4（PR #47） ｜ 抽取日期：2026-11-07 ｜ 静态校验：通过（import 闭包与禁物扫描、TypeScript `--noEmit`、模块定向测试；完整套件另有 3 个上游群聊断言失败，详见 `ledger.md`）

## 拷入

将本包内 `server/` 目录按相同路径复制进项目（本暂存目录届时已位于项目根）。只复制后端实现与随行测试，不包含前端文件。

- 包内包含六个平台的 mock/real 实现及对应测试；真实平台密钥仍按各平台请求契约传入，不落入暂存包。

## 缝合（共 2 处，全部单行插入）

1. `server/src/index.ts` 的路由 import 区，新增一行：

   ```ts
   import socialPublishRouter from './routes/social/social-publish';
   ```

2. `server/src/index.ts` 的 `proxyFallback` 之前，新增一行：

   ```ts
   app.use('/api/social-publish', socialPublishRouter);
   ```

无新增 npm / Python 依赖，无需修改 `package.json` 或 `pyproject.toml`。

## 契约文档补丁（合入时照抄以下文字追加，含 ⏳ 标记）

- 《新前端对接契约.md》B.2 接口面追加：`/api/social-publish`：社交账号与营销帖管理、六平台 mock/real 发布、发布日志及统计。
- B.5 错误码追加：`ACCOUNT_NOT_FOUND` (404) 社交账号不存在；`POST_NOT_FOUND` (404) 帖子不存在；`PRODUCT_NOT_FOUND` (404) 商品不存在；`INTERNAL` (500) 社交发布内部错误。
- B.7 上述 `social-publish` 相关条目后统一标注：`⏳ 前端未接入`

## 验证（合入方执行）

在项目根运行定向测试：

```bash
cd server && npx vitest run --maxWorkers=2 src/__tests__/social-publish.test.ts src/__tests__/social-platforms-real.test.ts
```

运行完整后端检查：

```bash
cd server && npx tsc --noEmit && npx vitest run --maxWorkers=2
```

启动网关后，在另一终端冒烟：

```bash
node scripts/dev.mjs --no-open
curl http://localhost:8002/api/social-publish/platforms
```
